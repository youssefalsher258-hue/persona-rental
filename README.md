### A personality for every occasion.

Tired of being you? Borrow someone better suited to the occasion!

**Persona Rentals** is a fun, interactive website where users can generate fictional personalities, explore their unique traits, and rent them for different occasions.

## 🌐 Live Demo

[Visit Persona Rentals](https://speedy-aurora-osu7si6.tmp.now/)

## ✨ Features

- 🎲 **Random Personality Generator** – Generate unique fictional personalities.
- 🎭 **Personality Archetypes** – Discover fun and unusual character types.
- 📊 **Personality Statistics** – Explore randomized traits and scores.
- 🎨 **Dynamic Personalities** – Every generated personality is different.
- ⏳ **Flexible Rental Plans** – Choose from different rental durations.
- ➕ **Custom Add-ons** – Add confidence boosts, sarcasm filters, and more.
- 💰 **Dynamic Pricing** – Automatically calculates rental costs.
- 📜 **Rental Confirmation** – Generates a fictional rental agreement.
- 📱 **Responsive Design** – Designed to work on mobile and desktop.
- 🌙 **Dark Mode Support** – Adapts to the user's preferred color scheme.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts – Bricolage Grotesque

## 🚀 Getting Started

You can run the project locally:

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation or additional dependencies required.

```text
persona-rentals/

├── index.html

```
